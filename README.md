# Собеседник-бот (Telegram + TokenHarbor)

Бот для личного использования: отвечает коротко, спорит по делу, не льстит.
Понимает текст и голосовые. Доступ закрыт на владельца через `TELEGRAM_OWNER_ID`.

Модель: `deepseek-v4.1-flash:free` через OpenAI-совместимый API TokenHarbor.

## Запуск

1. Установи зависимости:

   ```powershell
   pip install -r requirements.txt
   ```

2. Создай `.env` по образцу `.env.example` и заполни:

   - `TELEGRAM_TOKEN` — токен из [@BotFather](https://t.me/BotFather) (`/mybots` → бот → API Token).
   - `TOKENHARBOR_API_KEY` — ключ с https://tokenharbor.ai/dashboard.
   - `TELEGRAM_OWNER_ID` — твой Telegram ID. Если не знаешь: оставь пустым,
     запусти бота, отправь ему `/id`, полученное число впиши в `.env`.
   - `MODEL` — необязательно, по умолчанию `deepseek-v4.1-flash:free`.

3. Запусти:

   ```powershell
   python bot.py
   ```

## Голосовые сообщения

Нужен бесплатный ключ Groq: https://console.groq.com/keys

1. Зарегистрируйся, создай API key.
2. Добавь в `.env` (и в переменные окружения на хостинге):

   ```
   GROQ_API_KEY=gsk_...
   ```

3. Перезапусти бота. Голосовое распознаётся через `whisper-large-v3-turbo`,
   расшифровка приходит в чат, затем бот отвечает на неё как на текст.

Без ключа бот продолжает работать, но на голосовые отвечает подсказкой.
Можно подключить любой другой OpenAI-совместимый STT через `STT_URL` и `STT_MODEL`.

## Лимиты TokenHarbor

Бесплатные модели доступны без баланса: `deepseek-v4.1-flash:free`,
`deepseek-v4-flash:free`, `mimo-v2.5:free`, `mimo-v2.6-flash:free`.
На платных моделях при балансе $0 приходит ошибка 402 — бот показывает её текстом.

## Почему бот иногда называет себя Claude или GPT

Самоидентификация языковых моделей ненадёжна: модель не знает своё настоящее имя, а в обучающих данных много ответов вида «я Claude» и «я ChatGPT». Проверка на TokenHarbor это подтверждает: одна и та же free-модель на вопрос «кто ты» отвечает то «ChatGPT от OpenAI», то «DeepSeek», то «Qwen от Alibaba», а `mimo` — то «XAI», то «YandexGPT». Это не подмена модели на стороне API, а галлюцинация.

Поэтому в системный промпт добавлена явная идентичность: бот представляется как Honest Challenger на `deepseek-v4.1-flash:free` через TokenHarbor и не приписывает себе чужие названия.

## Команды

- `/start` — приветствие.
- `/id` — показать твой Telegram ID (нужно для `TELEGRAM_OWNER_ID`).
- `/reset` — очистить историю диалога.

## Важно про хостинг

Telegram отдаёт обновления только одному поллеру на токен. Если бот уже запущен
на Bothost и ты запускаешь его локально с тем же токеном, второй экземпляр упадёт
с ошибкой `Conflict: terminated by other getUpdates request`.

Поэтому перед локальным запуском останови сервис в панели Bothost, либо в
@BotFather выполни `/revoke` и обнови токен везде.

## Что внутри

- Проверка обязательных переменных окружения с понятным сообщением вместо `KeyError`.
- Поддержка `.env` (python-dotenv).
- Бот привязан к владельцу (`TELEGRAM_OWNER_ID`), чужие сообщения игнорируются и логируются.
- `delete_webhook` перед polling — не будет 409, если раньше был webhook.
- Деление длинных ответов по лимиту Telegram в UTF-16 (эмодзи не ломают отправку).
- Одна HTTP-сессия на всё приложение, повторы на 429/5xx/таймаут.
- Порядок ответов сохраняется: отправка идёт под тем же lock, что и запрос.
- Индикатор «печатает» обновляется, пока модель думает.
- История режется по репликам, служебные поля модели не хранятся.
- Пустой ответ модели не попадает в историю.
- Голосовые: скачивание из Telegram → Whisper (Groq) → обычный ответ.
