# Собеседник-бот (Telegram + OpenRouter)

Бот для личного использования: отвечает коротко, спорит по делу, не льстит.
Доступ закрыт на владельца через `TELEGRAM_OWNER_ID`.

## Запуск

1. Установи зависимости:

   ```powershell
   pip install -r requirements.txt
   ```

2. Создай `.env` по образцу `.env.example` и заполни:

   - `TELEGRAM_TOKEN` — токен из [@BotFather](https://t.me/BotFather) (`/mybots` → бот → API Token).
   - `OPENROUTER_API_KEY` — ключ с https://openrouter.ai/keys.
   - `TELEGRAM_OWNER_ID` — твой Telegram ID. Если не знаешь: оставь пустым,
     запусти бота, отправь ему `/id`, полученное число впиши в `.env`.

3. Запусти:

   ```powershell
   python bot.py
   ```

## Команды

- `/start` — приветствие.
- `/id` — показать твой Telegram ID (нужно для `TELEGRAM_OWNER_ID`).
- `/reset` — очистить историю диалога.

## Важно про хостинг

Telegram отдаёт обновления только одному поллеру на токен. Если бот уже запущен
на Bothost и ты запускаешь его локально с тем же токеном, второй экземпляр упадёт
с ошибкой `Conflict: terminated by other getUpdates request`.

Поэтому перед локальным запуском:

- останови сервис в панели Bothost, **или**
- в @BotFather выполни `/revoke` — старый токен перестанет работать везде,
  после чего впиши новый в `.env` (и на Bothost, если вернёшь туда).

## Что было исправлено

- Проверка обязательных переменных окружения с понятным сообщением вместо `KeyError`.
- Поддержка `.env` (python-dotenv).
- Бот привязан к владельцу (`TELEGRAM_OWNER_ID`), чужие сообщения игнорируются и логируются.
- `delete_webhook` перед polling — не будет 409, если раньше был webhook.
- Деление длинных ответов по лимиту Telegram в UTF-16 (раньше эмодзи ломали отправку).
- Одна HTTP-сессия на всё приложение, повторы на 429/5xx/таймаут.
- Порядок ответов сохраняется: отправка идёт под тем же lock, что и запрос.
- Индикатор «печатает» обновляется, пока модель думает.
- История режется по репликам, `reasoning_details` хранятся только у последнего ответа.
- Пустой ответ модели не попадает в историю.
- Ответ на нетекстовые сообщения.
